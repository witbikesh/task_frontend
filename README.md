# Task Management Dashboard (Vite + React + TypeScript)

## Project Overview

This is a **Task Management Dashboard** built with:

- **React** + **TypeScript**
- **Vite** as the build tool
- **React Query** for API data fetching and caching
- **Tailwind CSS** for styling

**Features:**

- Create, view, update, and manage tasks
- Track task status (pending, in-progress, completed)
- Search, sort, and paginate tasks
- View task statistics (total, completed, in-progress, pending)
- Integrates with a backend API for task CRUD operations

---

## Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/witbikesh/task_frontend.git
cd task_frontend
```

### 2. Environment Setup

Create a .env file in the project root with:

```bash
VITE_API_URL="your_server_url"
```

### 3. Install dependencies

```bash
npm i -g pnpm
pnpm install
```

### 4. Run project

```bash
pnpm dev
```
